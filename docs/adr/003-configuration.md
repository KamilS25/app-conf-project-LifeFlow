# ADR 003. Конфигурация и защита секретов

## Статус

Предложено, ожидает ревью PR.

## Контекст

После практики №3 приложение читало `DATABASE_URL` в обработчике `/health`. При отсутствии адреса процесс стартовал, а `/health` отвечал `503`. Документация API была открыта в любом окружении. Версия для `/version` и OpenAPI была задана в Python как `0.2.0`, а в `pyproject.toml` стояло `0.1.0`. Проверка на секреты перед коммитом отсутствовала.

Gitleaks 8.30.1 проверил всю доступную историю Git на исходной ветке `main` (`b4b1a80`). Просканировано 20 коммитов, находок нет. Ротация по результатам этой проверки не требуется.

## Решение

- Использовать `pydantic-settings` для проверки всех переменных приложения в `settings.py` при запуске. При ошибке назвать переменные без вывода их значений. Пароль и строку подключения хранить в `SecretStr`.
- Применять `APP_ENV=dev` по умолчанию. В `prod` отключать Swagger UI, ReDoc и выдачу схемы OpenAPI. `GET /health` в обоих режимах выполняет `SELECT 1` и сообщает о недоступности PostgreSQL кодом `503`.
- Оставить адрес `db:5432` и параметры аутентификации раздельными в Compose. Это позволяет передать пароль со спецсимволами без ручного URL-кодирования. При запуске напрямую параметры, явно указанные в `DATABASE_URL`, имеют приоритет над соответствующими `PG*`.
- Оставить `project.version` в `pyproject.toml` единственным источником версии приложения. `GET /version` и OpenAPI читают одну версию FastAPI. При обновлении версии `uv version <номер>` команда обновляет `pyproject.toml` и `uv.lock`.
- Установить pre-commit с базовыми проверками формата и Gitleaks 8.30.1 в Docker. Команда сканера проверяет индекс Git перед коммитом. `.gitignore` исключает `.env` и `.env.*`, оставляя в репозитории `.env.example`.

## Обоснование

| Вариант конфигурации | Оценка |
| --- | --- |
| Прямое чтение `os.environ` | Потребовались бы собственные проверки типов и обязательности, включая маскирование ошибок. |
| `python-dotenv` | Загружает значения, для проверки типов и правил проекта дополнительно понадобился бы собственный код. |
| `pydantic-settings` | Использует типизированные поля и общую проверку при старте. Pydantic уже используется FastAPI. |

Сравнили Gitleaks и detect-secrets. Gitleaks проверяет как изменения в индексе, так и историю Git одним инструментом. Закреплённая версия контейнера использует Docker, который нужен для запуска самого LifeFlow. `pyproject.toml` выбран источником версии, потому что uv уже обновляет её вместе с lock-файлом.

## Последствия

- Ошибки конфигурации обнаруживаются до начала обслуживания запросов. Для запуска приложения напрямую потребуется `DATABASE_URL` даже при проверке маршрута `/`.
- Проверка секретов перед коммитом требует работающего Docker. Первый запуск устанавливает окружения проверок и скачивает образ Gitleaks, если его ещё нет на машине.
- В финальный образ копируются окружение Python и файлы, необходимые для запуска. uv, его кэш, инструменты разработки и локальные конфигурации остаются вне образа.

## Переменные окружения

| Переменная | Назначение | По умолчанию | Источник при запуске Compose |
| --- | --- | --- | --- |
| `APP_ENV` | Режим API (`dev` или `prod`) | `dev` | Локальный env-файл или окружение терминала |
| `DATABASE_URL` | Строка подключения PostgreSQL | Обязательная | Compose задаёт адрес `postgresql://db:5432` |
| `DB_CONNECT_TIMEOUT` | Таймаут подключения к PostgreSQL, минимум 2 секунды | `3` | Умолчание приложения |
| `PGDATABASE`, `PGUSER`, `PGPASSWORD` | Параметры подключения, если не заданы в `DATABASE_URL` | Параметры libpq | Compose передаёт значения `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` |
| `POSTGRES_DB`, `POSTGRES_USER` | База и пользователь PostgreSQL | `lifeflow` | Локальный env-файл или окружение терминала |
| `POSTGRES_PASSWORD` | Пароль PostgreSQL | Обязательная в Compose | Локальный env-файл или окружение терминала |
| `APP_PORT` | Порт FastAPI на хосте | `8000` | Локальный env-файл или окружение терминала |

## Проверка Git-истории

В PowerShell из корня репозитория:

```powershell
docker run --rm --mount "type=bind,source=$($PWD.Path),target=/repo,readonly" --workdir /repo ghcr.io/gitleaks/gitleaks:v8.30.1 git --redact=100 --no-banner --log-opts=--all .
```

При обнаружении действующего секрета отзовите или замените его у поставщика, обновите рабочее окружение и зафиксируйте факт ротации без значения секрета.
