Система управления личными задачами, целями и финансами

Приложение предназначено для пользователей, которые хотят планировать личные дела, отслеживать цели и вести учёт доходов и расходов.

## Предметная область

- **Основная сущность:** Task (задача) — личное дело пользователя с названием, необязательным описанием, статусом и необязательным сроком выполнения.
- **Пользователи:** люди, которым нужно планировать личные дела, отслеживать их выполнение и соблюдать сроки, например студенты и работающие специалисты. Каждый пользователь управляет собственными задачами.
- **Планируемые эндпоинты:**
  - `POST /tasks` — создать задачу.
  - `GET /tasks` — получить список задач с пагинацией.
  - `GET /tasks/{id}` — получить одну задачу по идентификатору.
  - `PUT /tasks/{id}` — изменить задачу.
  - `DELETE /tasks/{id}` — удалить задачу.

Эндпоинты Task запланированы для следующих этапов разработки и в практической работе №1 не реализуются.
